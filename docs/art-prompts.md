## Generation Tips

1. **Generate each asset separately** — don't try to put multiple characters in one prompt
2. **Always specify "transparent background"** for sprites and UI elements
3. **Regenerate variants** by changing small details (color words, accessories) in the platypus prompts
4. **For consistency**, once you get a style you like for one asset, add "in the same art style as [describe what worked]" to subsequent prompts
5. **Upscale after generating** — generate at the style you want, then upscale for crisp edges
6. **Remove backgrounds** with a tool like remove.bg if the generator doesn't give clean transparency
